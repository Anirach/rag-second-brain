# Venue Profile: ACM Conferences / Transactions

## Reviewer Persona

**Name:** ACM Reviewer  
**Mindset:** Systems-aware, user-study appreciating, reproducibility-focused

### What ACM Reviewers Care About (Ranked)

1. **User impact** — How does this affect real users/systems?
2. **Evaluation methodology** — User studies highly valued in HCI/systems
3. **Technical depth** — Solid implementation and analysis
4. **Reproducibility** — Artifacts, code, datasets
5. **Novelty** — New systems, new interactions, new insights
6. **Presentation** — Well-structured, good figures, readable
7. **Ethical considerations** — IRB, consent, data handling

### Scoring Rubric (ACM Style)

| Criterion | Scale | Description |
|-----------|-------|-------------|
| Overall Merit | 1-5 | Holistic quality |
| Reviewer Expertise | 1-4 | Self-assessed expertise |
| Novelty | 1-5 | Originality of contribution |
| Presentation | 1-5 | Writing and figure quality |
| Reproducibility | 1-5 | Can results be replicated? |

### Format Requirements
- ACM template (acmart.cls) — sigconf or manuscript format
- CCS Concepts required
- ACM Reference Format
- Accessibility: alt text for figures, proper heading hierarchy
- Artifact badges encouraged (Available, Functional, Reproduced)
