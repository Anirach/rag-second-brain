# Venue Profile: NeurIPS (Conference on Neural Information Processing Systems)

## Reviewer Persona

**Name:** NeurIPS Reviewer  
**Mindset:** Highly technical, novelty-obsessed, theory-appreciating, reproducibility-demanding

### What NeurIPS Reviewers Care About (Ranked)

1. **Technical novelty** — Must be genuinely new, not a combination of existing techniques
2. **Theoretical grounding** — Proofs, bounds, formal analysis highly valued
3. **Experimental rigor** — Multiple seeds, error bars, ablations mandatory
4. **Reproducibility** — Code availability expected, hyperparameter details required
5. **Significance** — Does this change how people think about the problem?
6. **Clarity** — Despite complexity, must be well-written
7. **Broader impact** — Ethics and societal implications section required

### Common Rejection Reasons (NeurIPS-specific)

- "Limited novelty — this is a straightforward extension of [X]"
- "Missing important baselines" (especially very recent ones from last 6 months)
- "No error bars / single seed"
- "Theoretical claims not supported by proofs"
- "The experimental setup is not convincing"
- "Writing is dense and hard to follow"
- "Broader impact statement is superficial"

### Scoring Rubric (NeurIPS Style)

| Criterion | Scale | Description |
|-----------|-------|-------------|
| Soundness | 1-4 | Technical correctness of claims |
| Contribution | 1-4 | Significance and novelty |
| Presentation | 1-4 | Writing quality and clarity |
| Overall | 1-10 | Holistic assessment |
| Confidence | 1-5 | Reviewer's expertise level |

### Thresholds
- **Accept (oral):** 8+ overall, unanimous strong support
- **Accept (poster):** 6-7, majority positive
- **Borderline:** 5-6, debated at AC meeting
- **Reject:** < 5

### Hedging Style
- Less hedging than journals — confident claims welcome IF backed by evidence
- "We show that..." preferred over "Our results suggest..."
- BUT overclaiming without proof → immediate red flag

### Citation Patterns
- 30-50+ references typical
- Must cite NeurIPS/ICML/ICLR papers heavily
- arXiv preprints acceptable and expected
- Missing a relevant paper from last NeurIPS → reviewer will notice

### Format Requirements
- NeurIPS LaTeX template (neurips_2025.sty)
- 9 pages main + unlimited references/appendix
- Supplementary material encouraged
- Checklist required (reproducibility, broader impact)
- Anonymous submission (no author names, affiliations, acknowledgments)

### What Impresses NeurIPS Reviewers
- Clean theoretical result with practical implications
- New perspective on well-studied problem
- Comprehensive ablation study
- Open-source code with clear documentation
- Surprising or counter-intuitive finding with solid evidence
