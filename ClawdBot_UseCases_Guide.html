USE CASE 1

Personal Telegram Assistant

Your 24/7 AI companion accessible from anywhere via Telegram

Overview

Transform ClawdBot into your personal Telegram assistant that's always available. Whether you're on your phone, tablet, or desktop, you can chat with your AI assistant, set reminders, look up information, manage files in your workspace, and automate daily tasks—all through the familiar Telegram interface.

Why it's useful:

  • Access your AI assistant from any device with Telegram installed
  • Secure pairing system ensures only you can interact with your bot
  • Native Telegram features: inline keyboards, reactions, voice messages
  • Persistent conversation history across sessions
  • Support for images, documents, and media sharing

Prerequisites

  • 📱 Telegram account
  • 🤖 Telegram bot token from @BotFather
  • 🖥️ ClawdBot installed and running
  • 🔑 AI provider API key (Anthropic/OpenAI)

Step-by-Step Setup

1

Create a Telegram Bot

Open Telegram and search for @BotFather. Start a chat and send /newbot. Follow the prompts to name your bot (e.g., "My Clawd Assistant") and choose a username ending in "bot" (e.g., myclawd_bot). Copy the bot token provided.

2

Configure BotFather Settings (Optional but Recommended)

In BotFather, run these commands for your bot:

  • /setprivacy → Disable (to see all group messages)
  • /setjoingroups → Enable (to add to groups)
  • /setdescription → Add a description
3

Configure ClawdBot

Edit your configuration file at ~/.clawdbot/clawdbot.json:

Configuration Examples

Minimal Configuration

{
  "channels": {
    "telegram": {
      "enabled": true,
      "botToken": "123456789:ABCdefGHI...",
      "dmPolicy": "pairing"
    }
  }
}

Full-Featured Configuration

{
  "identity": {
    "name": "Clawd",
    "theme": "helpful AI assistant",
    "emoji": "🦞"
  },
  "channels": {
    "telegram": {
      "enabled": true,
      "botToken": "123456789:ABCdefGHI...",
      "dmPolicy": "pairing",
      "allowFrom": ["123456789"], // Your Telegram user ID
      "textChunkLimit": 4000,
      "mediaMaxMb": 10,
      "reactionLevel": "minimal",
      "streamMode": "partial",
      "groups": {
        "*": { "requireMention": true }
      },
      "customCommands": [
        { "command": "backup", "description": "Git backup workspace" },
        { "command": "weather", "description": "Get weather report" }
      ]
    }
  },
  "messages": {
    "ackReaction": "👀",
    "ackReactionScope": "group-mentions",
    "removeAckAfterReply": true
  }
}
To find your Telegram user ID, DM your bot after starting the gateway and check the logs with clawdbot logs --follow, or DM @userinfobot on Telegram.

Tips & Best Practices

Use dmPolicy: "pairing" for security. When someone new messages your bot, they receive a pairing code that you must approve with clawdbot pairing approve telegram <code>.
Keep your bot token secret! Never commit it to version control. Use environment variables: TELEGRAM_BOT_TOKEN=...
  • Enable reactions — Set reactionLevel: "minimal" for natural conversation flow
  • Use streaming — streamMode: "partial" shows real-time typing for better UX
  • Group mentions — Always use requireMention: true in groups to avoid noise
  • Custom commands — Add frequently used actions to the Telegram menu
  • History limit — Adjust historyLimit to control context window size
USE CASE 2

Automated Daily Briefings

Wake up to personalized summaries delivered right to your chat

Overview

ClawdBot's built-in cron scheduler lets you automate recurring tasks like morning briefings, news summaries, weather updates, and calendar digests. Jobs can run at specific times, deliver output to any configured channel, and use different AI models for different tasks.

Why it's useful:

  • Start your day with a personalized summary without lifting a finger
  • Consolidate information from multiple sources into one digest
  • Schedule reminders and check-ins automatically
  • Run background research tasks during off-hours
  • Persist jobs across gateway restarts

Prerequisites

  • 🖥️ ClawdBot Gateway running continuously
  • 📱 At least one channel configured (Telegram/Discord/etc.)
  • 🌐 Web search enabled (for news/weather)
  • 📅 Calendar integration (optional, for digests)

Step-by-Step Setup

1

Ensure Cron is Enabled

Cron is enabled by default. Verify in your config or check status:

clawdbot cron list
2

Create a Morning Briefing Job

Use the CLI to add a cron job that runs every morning:

clawdbot cron add \
  --name "Morning Briefing" \
  --cron "0 7 * * *" \
  --tz "America/New_York" \
  --session isolated \
  --message "Create a morning briefing with: 1) Today's weather forecast 2) Top 3 news headlines 3) My calendar events for today" \
  --deliver \
  --channel telegram \
  --to "123456789"
3

Test the Job

Force-run to verify it works:

clawdbot cron run <jobId> --force

Configuration Examples

Cron Configuration in clawdbot.json

{
  "cron": {
    "enabled": true,
    "store": "~/.clawdbot/cron/jobs.json",
    "maxConcurrentRuns": 1
  }
}

CLI Examples for Different Briefings

Weekly Summary (Every Monday at 9 AM):

clawdbot cron add \
  --name "Weekly Summary" \
  --cron "0 9 * * 1" \
  --tz "America/Los_Angeles" \
  --session isolated \
  --message "Summarize my week: review calendar, check pending tasks, suggest priorities" \
  --model "opus" \
  --thinking high \
  --deliver \
  --channel telegram \
  --to "123456789"

Evening News Digest (Daily at 6 PM):

clawdbot cron add \
  --name "Evening News" \
  --cron "0 18 * * *" \
  --tz "Europe/London" \
  --session isolated \
  --message "Search for today's top tech news and give me a 5-bullet summary" \
  --deliver \
  --channel discord \
  --to "channel:123456789"

One-Shot Reminder (Auto-delete after run):

clawdbot cron add \
  --name "Meeting Reminder" \
  --at "2025-01-15T14:30:00Z" \
  --session main \
  --system-event "Reminder: Team standup in 30 minutes!" \
  --wake now \
  --delete-after-run

Managing Cron Jobs

# List all jobs
clawdbot cron list

# View job details
clawdbot cron status <jobId>

# Edit an existing job
clawdbot cron edit <jobId> --message "Updated prompt"

# View run history
clawdbot cron runs --id <jobId> --limit 10

# Remove a job
clawdbot cron remove <jobId>

Tips & Best Practices

Use --session isolated for briefings to keep them separate from your main conversation history. This also prevents noisy jobs from cluttering your chat context.
Cron expressions use 5 fields: minute, hour, day-of-month, month, day-of-week. Example: 0 7 * * 1-5 = 7 AM on weekdays only.
  • Set timezone explicitly — Use --tz to avoid confusion with server timezone
  • Use model overrides wisely — Save costs with smaller models for simple briefings
  • Enable web search — Required for news and weather lookups
  • Review run history — Check ~/.clawdbot/cron/runs/ for debugging
  • Batch similar tasks — Combine related checks into one briefing to reduce API calls
USE CASE 3

GitHub & Developer Workflow

Supercharge your development workflow with AI-powered GitHub integration

Overview

ClawdBot can interact with GitHub repositories using the gh CLI, enabling you to check PR status, review code changes, monitor CI/CD pipelines, manage issues, and get coding assistance—all through natural conversation.

Why it's useful:

  • Check CI status and review PRs without leaving your chat
  • Get instant notifications on workflow failures
  • Ask questions about code changes and get AI explanations
  • Automate issue triage and labeling
  • Generate release notes and changelogs

Prerequisites

  • 🐙 GitHub account with repository access
  • ⚙️ gh CLI installed and authenticated
  • 🖥️ ClawdBot with exec tool enabled
  • 🔑 Appropriate GitHub permissions

Step-by-Step Setup

1

Install and Authenticate GitHub CLI

# Install gh (varies by OS)
brew install gh  # macOS
sudo apt install gh  # Ubuntu/Debian

# Authenticate
gh auth login
2

Enable the GitHub Skill

The GitHub skill is built into ClawdBot. Ensure the exec tool is enabled in your security policy.

3

Set Up Workspace Context (Optional)

Add project context to your workspace's AGENTS.md for better assistance:

# In ~/clawd/AGENTS.md
## GitHub Repositories
- Main project: owner/my-project
- Docs: owner/my-docs

Configuration Examples

Tool Policy Configuration

{
  "tools": {
    "exec": {
      "enabled": true,
      "allowlist": [
        "gh",
        "git"
      ]
    }
  }
}

GitHub Skill Reference (SKILL.md)

ClawdBot includes a built-in GitHub skill that knows how to use the gh CLI:

# Check CI status on a PR
gh pr checks 55 --repo owner/repo

# List recent workflow runs
gh run list --repo owner/repo --limit 10

# View a specific run
gh run view <run-id> --repo owner/repo

# View failed step logs
gh run view <run-id> --repo owner/repo --log-failed

# API queries with jq filtering
gh api repos/owner/repo/pulls/55 --jq '.title, .state, .user.login'

# JSON output with custom formatting
gh issue list --repo owner/repo --json number,title \
  --jq '.[] | "\(.number): \(.title)"'

Tips & Best Practices

Always specify --repo owner/repo when not in a git directory, or clone repositories into your ClawdBot workspace for automatic detection.
  • Use JSON output — --json flag gives structured data for complex queries
  • Filter with jq — The --jq flag helps extract exactly what you need
  • Set up webhooks — Use ClawdBot's webhook feature for real-time PR notifications
  • Create templates — Save common queries in your workspace for quick access
  • Review permissions — Use a GitHub token with minimal required scopes

Multi-Channel Communication Hub

Connect Telegram, Discord, and Slack through a unified AI assistant

Overview

ClawdBot supports multiple communication channels simultaneously. You can connect Telegram for personal use, Discord for community/team interactions, and Slack for work—all sharing the same AI brain but with channel-specific configurations and sessions.

Why it's useful:

  • One assistant, accessible everywhere you communicate
  • Channel-specific settings (mention rules, skills, prompts)
  • Cross-post messages between platforms
  • Unified notification management
  • Consistent AI personality across all channels

Prerequisites

  • 📱 Telegram bot token
  • 🎮 Discord bot token + application
  • 💼 Slack app + bot tokens
  • 🖥️ ClawdBot Gateway running

Step-by-Step Setup

1

Create Bot Accounts for Each Platform

  • Telegram: @BotFather → /newbot
  • Discord: Developer Portal → New Application → Bot
  • Slack: api.slack.com → Create App → Enable Socket Mode
2

Configure Each Channel

Add all channel configurations to your clawdbot.json:

USE CASE 5

Smart Research & Web Automation

Leverage AI-powered web search, content extraction, and browser automation

Overview

ClawdBot includes powerful web tools: web_search for real-time search queries, web_fetch for extracting readable content from URLs, and a full browser automation system for complex tasks requiring JavaScript execution or authenticated sessions.

Why it's useful:

  • Research topics and get synthesized answers with citations
  • Extract and summarize content from any webpage
  • Automate browser tasks (form filling, data extraction, testing)
  • Generate documents from research findings
  • Monitor websites for changes

Prerequisites

  • 🔍 Brave Search API key (free tier available)
  • 🌐 Optional: Firecrawl API key for better extraction
  • 🖥️ Optional: Chromium browser for automation
  • 🔑 Optional: OpenRouter/Perplexity for AI search

Step-by-Step Setup

1

Get a Brave Search API Key

Sign up at brave.com/search/api and create an API key. The free tier includes 2,000 queries/month.

2

Configure Web Tools

Run the configure wizard or edit your config manually:

clawdbot configure --section web
3

Enable Browser Automation (Optional)

For advanced tasks requiring JavaScript or logins:

clawdbot browser --browser-profile clawd start

Configuration Examples

Web Search Configuration

{
  "tools": {
    "web": {
      "search": {
        "enabled": true,
        "provider": "brave",
        "apiKey": "BSA...",
        "maxResults": 5,
        "timeoutSeconds": 30,
        "cacheTtlMinutes": 15
      },
      "fetch": {
        "enabled": true,
        "maxChars": 50000,
        "timeoutSeconds": 30,
        "readability": true
      }
    }
  }
}

Perplexity Search (Alternative to Brave)

{
  "tools": {

        "enabled": true,
        "provider": "perplexity",

          "model": "perplexity/sonar-pro"

  }
}

  "browser": {
    "enabled": true,

Tips & Best Practices

Use web_fetch for static content and the browser tool for JavaScript-heavy sites. The browser tool is more powerful but slower and more resource-intensive.
Results from web_search and web_fetch are cached for 15 minutes by default. Adjust cacheTtlMinutes for time-sensitive research.
Tool Best For Limitations
web_search Finding information, news, facts Returns snippets, not full content
web_fetch Reading articles, documentation No JavaScript execution
Browser Complex automation, SPAs, logins Slower, requires more resources
  • Use search parameters — Specify country, freshness for targeted results
  • Chain tools effectively — Search → Fetch most relevant → Summarize
  • Browser profiles — Use separate profiles for different automation tasks
  • Respect rate limits — Brave free tier has daily limits
  • Consider Perplexity — For synthesized answers vs. raw search results
