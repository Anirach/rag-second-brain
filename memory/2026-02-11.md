**👥 Team Mode (Collaborative):**

- Feature branches for parallel work
- pr-agent handles integration/merge
- Communication protocol for shared files
- Sequential merge order to avoid conflicts



### Coding Team: Human Collaboration Mode Added
Agents now work alongside human developers:

**Workflow:**
1. Human assigns task to agent team
2. Agent creates feature branch (feature/agent-xxx)
3. Parallel work: Agent on their part, Human on theirs
4. Agent pushes and creates Pull Request
5. Human reviews PR on GitHub/GitLab
6. Agent addresses feedback if needed
7. Human approves & merges

**Features:**
- Branch naming convention (feature/agent-*, fix/agent-*)
- Commit message standards (feat/fix/refactor/perf/test/docs)
- PR template with summary, files changed, testing notes
- Review feedback loop - agent addresses comments
- Communication protocol between agent and human
