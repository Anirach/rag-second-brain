## 🚀 Powerful Skill Combinations

```

```
**Use Case**: Creating comprehensive technical curriculum with research backing, quality content, and professional code examples.

### Multimedia Content Pipeline
```
Writing (content-quality-auditor) → Translation (edge-tts) → Course (video-subtitles) → All (mermaid-architect)
```
**Use Case**: Creating high-quality multimedia educational content with professional narration, captions, and visual aids.

### Academic Publication Pipeline
```
Academic (literature-review) → Writing (content-quality-auditor) → Academic (latex) → Translation (edge-tts) → Course (google-slides)
```
**Use Case**: Complete academic publication with quality validation, professional formatting, audio abstract, and presentation materials.

## 🔗 Implementation Guidelines

### When to Use Cross-Team Skills

1. **Quality Enhancement**: Always use content-quality-auditor for any public-facing content
2. **Research Validation**: Combine literature-search with deep-research-pro for comprehensive research
3. **Visual Communication**: Use mermaid-architect and diagram for any technical documentation
4. **Format Flexibility**: Use markdown-converter for multi-format deliverables
5. **Accessibility**: Use edge-tts and video-subtitles for inclusive content

### Best Practices

1. **Skill Attribution**: Always credit the source team when using their skills
2. **Quality Gates**: Use appropriate skill-based validation before delivery
3. **Format Standards**: Ensure all outputs meet professional standards using relevant skills
4. **Cross-Validation**: Use multiple teams' skills for critical content validation
5. **Documentation**: Document skill usage for future reference and improvement
