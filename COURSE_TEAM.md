# Course Preparation Team — Professional Course Material Pipeline

## 🎯 Mission

Generate complete, professional course materials from minimal input:
- **Input:** Course name, description, number of lectures, lecture duration
- **Output:** HTML slides, lecture handouts (DOCX), full course book (DOCX) with assessments

## 🚀 Full Auto Mode

One spawn → Complete course package.

```
[Course Requirements] ──► course-architect ──► [Complete Course Package]
                                │
                                ├── 1. Analyze requirements
                                ├── 2. Design curriculum structure
                                ├── 3. Create lecture outlines
                                ├── 4. Generate content for each lecture
                                ├── 5. Create HTML slides (light gray theme)
                                ├── 6. Generate handouts (DOCX)
                                ├── 7. Compile course book with assessments
                                ├── 8. Quality review
                                └── 9. Upload to Google Drive (subfolder)
```

**To create a course:**
```
Arthur, create course materials:
- Course name: [NAME]
- Description: [DESCRIPTION]
- Number of lectures: [N]
- Lecture duration: [X hours/minutes]
```

## 🏆 Agent Quality Standards

### course-architect (Director)
**Standard:** Executive-level course design
- ✅ Clear, measurable learning outcomes
- ✅ Logical topic progression (no gaps, no jumps)
- ✅ Appropriate depth for target audience
- ✅ Industry-relevant curriculum
- ✅ Balanced theory and practice (60/40 or 50/50)
- ❌ REJECT: Vague objectives, disconnected topics, outdated content

### curriculum-designer (Learning Design)
**Standard:** Pedagogically sound structure
- ✅ Bloom's Taxonomy aligned objectives (Remember → Create)
- ✅ Scaffolded learning (build on previous lectures)
- ✅ Active learning opportunities every 15-20 minutes
- ✅ Multiple learning modalities (visual, textual, hands-on)
- ✅ Formative + summative assessments
- ❌ REJECT: Passive lecture-only design, no engagement points

### content-writer (Content Creation)
**Standard:** Clear, accurate, engaging content
- ✅ Concise explanations (no filler)
- ✅ Real-world, modern examples (2024+)
- ✅ Analogies for complex concepts
- ✅ Consistent terminology throughout
- ✅ Proper citations for facts/statistics
- ✅ Code examples that actually work
- ❌ REJECT: Verbose text, outdated examples, unexplained jargon

### slide-designer (Visual Design)
**Standard:** Professional presentation quality
- ✅ One main idea per slide
- ✅ Readable fonts (min 24pt for body)
- ✅ Consistent color scheme
- ✅ High-contrast text (dark on light)
- ✅ Meaningful visuals (not decorative clip art)
- ✅ Syntax-highlighted code blocks
- ✅ Proper slide numbering and headers
- ❌ REJECT: Wall of text, tiny fonts, inconsistent styling

### assessment-creator (Evaluation Design)
**Standard:** Valid, reliable assessments
- ✅ Directly aligned to learning objectives
- ✅ Clear, unambiguous questions
- ✅ Mix of difficulty levels (Easy 40%, Medium 40%, Hard 20%)
- ✅ Variety of question types
- ✅ Detailed answer explanations
- ✅ No trick questions
- ❌ REJECT: Ambiguous wording, misaligned questions, no answer key

### book-compiler (Publication)
**Standard:** Publication-ready documents
- ✅ Professional formatting (consistent headers, margins, fonts)
- ✅ Working table of contents
- ✅ Page numbers on all pages
- ✅ Proper figure/table numbering
- ✅ Cross-references work correctly
- ✅ Print-ready quality (no broken layouts)
- ❌ REJECT: Inconsistent formatting, missing sections, broken TOC

### course-reviewer (Quality Assurance) ⭐ NEW
**Standard:** Rigorous quality gate
- ✅ Reviews ALL deliverables before final delivery
- ✅ Checks continuity across lectures
- ✅ Verifies code examples run correctly
- ✅ Tests all assessments for clarity
- ✅ Ensures consistency in terminology
- ✅ Validates against learning objectives
- ✅ Provides specific, actionable feedback
- ✅ Final sign-off required before upload

**Review Checklist:**
```markdown
## Course Review Checklist

### Content Quality
- [ ] All learning objectives are measurable
- [ ] Content matches stated difficulty level
- [ ] Examples are modern and relevant
- [ ] No factual errors or outdated information
- [ ] Terminology is consistent throughout

### Technical Quality (Programming Courses)
- [ ] All code examples run without errors
- [ ] Code follows best practices
- [ ] Dependencies are documented
- [ ] Solutions are correct

### Visual Quality
- [ ] Slides are readable and consistent
- [ ] No typos or grammatical errors
- [ ] Figures are clear and labeled
- [ ] Formatting is professional

### Pedagogical Quality
- [ ] Logical progression between lectures
- [ ] Assessments align with objectives
- [ ] Mix of difficulty levels appropriate
- [ ] Active learning opportunities included

### Completeness
- [ ] All lectures have slides
- [ ] All lectures have handouts
- [ ] Course book is complete
- [ ] All code examples included
- [ ] Answer keys provided

### Final Approval
- [ ] APPROVED for delivery
- [ ] REVISIONS NEEDED: [list issues]
```
