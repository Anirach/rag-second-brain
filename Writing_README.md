## 🚀 Operating Modes

### Full Auto Mode (Default)
- **book-architect** handles entire pipeline solo
- One spawn → complete book
- Enhanced with **deep-research-pro** and **content-quality-auditor**

### Human Collaboration Mode
- Iterative back-and-forth workflow
- Review at each stage with skill-enhanced quality gates
- **content-quality-auditor** validation at each checkpoint

### Manual/Step-by-Step
- Spawn individual specialists for control
- Skill-based quality validation at each stage
- Best for complex/sensitive projects
